# 能力地图（用户不知道能做什么时先看）

这张表是“用户可以直接怎么说”的索引，不是完整功能文档。主技能负责制卡主流程，其余按任务路由到支链。

| 用户想做什么 | 可以直接说 | 由谁执行 |
|---|---|---|
| 做卡、改卡、操作牌组 | “把这些材料做成墨墨记忆卡”“把这几张卡改一下” | `memo-cardest` |
| **批量删除卡片** | “把这些卡批量删掉”“清理这些卡” | **`memo-cardest` 内置**：移入 `DELETE` 章，最后由用户手动删章 |
| 表格 | “这张表做成表格卡”“用 LaTeX 表格” | `memo-canvas`（G1.5 强制触发） |
| 图像重绘 | “这张公式图/化学结构/流程图保留或重画” | `memo-canvas`（G1.4.1 强制触发） |
| 生成 TXT 自行导入 | “生成 TXT，我自己导入”“不碰 API” | `memo-txt` |
| 扫描件、PDF、图片 OCR | “先 OCR 再制卡”“这份扫描 PDF 转 Markdown” | `memo-mineruocr` |
| 卡片互链、目录跳转 | “给这两张卡加双向链接”“目录卡指向详情” | `memo-cardlink`（卡跳跳） |
| Anki 图片挖空迁墨 | “把 Anki 图片挖空卡迁到墨墨” | `memo-ankigo`（迁墨） |
| 墨墨产品使用问题 | “这个设置在哪”“TXT 怎么导入” | `memo-qahelper` |
| 自动更新 | “以后自动帮我同步” | `memo-cardest` 的安装器 + 沙箱外任务 |

## 重要区分

- **批量删除不是独立技能**：它是 `memo-cardest` 的内置流程。用户不需要安装额外技能，也不应该被告知“去装一个删除技能”。
- **表格不是主技能手画**：发现真实表格必须调用 `memo-canvas`；主技能只负责触发和把结果放进卡片。
- **图像重绘也不是主技能手画**：公式图、化学结构、流程图由 `memo-canvas` 选择原样/高清/重绘；OCR 文本不能替代结构还原。
- **TXT 路线不读凭证**：选 TXT 不需要 API key 或账户请求；但单卡上限按会员不同（专业版 5000 / 非专业版 2000），所以要确认会员状态。
- **OCR 只是前置**：OCR 成功不等于知识拆解或卡片语法验收。
- **卡跳跳只改引用**：不新建卡片、不移动卡片。

## 用户第一次问“你能做什么”时

用 6–8 行列出上表的能力，重点单独点出“批量删除是内置能力”，然后问“你想先做哪一件”。不要直接进入 G0 的 API/TXT 路线提问。
