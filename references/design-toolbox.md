# 从《🔥墨记工具箱》提炼的设计经验

来源：用户提供的《🔥墨记工具箱.txt》，2026-10-11 阅读。它包含社区妙招、颜色与排版案例、学习理论和 API 教程。以下是设计参考；语法可用性必须重新查官网和 tutuji。

## 学习卡片，而不是装饰笔记

- 简短、具体、可判分的问题优于“大段材料是什么”。一句解释可拆成定义、原因、条件、反例或应用问题，但不机械地把每句拆成独立事实。
- 不看到列表就一律做枚举卡。先判断项目是否有逻辑关系、需要顺序还是只需辨别。大型枚举可用“总览 → 按类别分项 → 情境题”；必要时在答案区附原始总览图，保留空间线索。
- 对关联多向的知识，使用真实情境模型和最具区分性的特征。不要把“突出作用”写成未经来源支持的“唯一作用”。完整复述要求不能被高频取舍替代。
- 口诀、解题技巧需要能实际应用的短题，不只问“口诀是什么”。反向卡仅在反向提取有学习价值且不产生歧义时添加。
- 来源图可以增强回忆线索，但图形必须有意义、获授权；不能因为文件里出现图片 ID 就假定能跨账户使用。

## 视觉层级与主题色

默认采用绿色强调，正文尽量保留客户端默认颜色。用一主色、一警示色、一辅助色建立一致语义，配色是可选默认，尊重用户指定风格。

| 用途 | 前景 | 浅背景 | 参考用途 |
|---|---|---|---|
| 墨绿 | 36b59d | e6f3f0 | 标题、概念、关键结论 |
| 朱红 | d16056 | faeae5 | 易错点、否定条件 |
| 琥珀 | eb9e27 | f9efdf | 注意、条件 |
| 蓝 | 6783cf | e9ecf7 | 解释、对照 |
| 紫 | 976bd1 | efe9f7 | 分类、拓展 |
| 中性灰 | 90959b | e5e6ea | 来源、注释（须检查对比度） |

绿色强调背景可用 `cae8e1`，蓝色标题背景 `cfdfff`，紫色标题背景 `dccafc`。工具箱的米棕风格组合为前景 `5e4b3f`、底色 `f2f2e6`、金黄强调 `debd43`。万事屋深色组合包括 `283b54`/`fefefe` 或 `262626`/`ffffff`，搭配 `6268ff`、`f93163`、`e77645`；只作为候选风格，不能保证暗模式可读。

颜色写成六位小写十六进制；语法参数使用 `!前景`、`!!背景`，不在颜色值前加额外 `#`。同一段文字的粗体、颜色等合并在一个 T 标签，不嵌套 T。

## 可复用版式（使用前仍查最新语法）

基础问答：

```text
[P#H1#[T#B,!36b59d#光合作用]]
光合作用主要发生在哪种细胞器？
---
[T#B#叶绿体。]
```

两段式小标签：

```text
[T#B,!ffffff,!!36b59d# 考点 ][T#B,!36b59d,!!e6f3f0# 细胞结构 ]
```

段落尽量左对齐，中心标题只用于简短内容。上下标 `up`/`down` 用于真实上下标，不能为了缩小整段正文滥用。Unicode 上下标覆盖不完整；科学表达优先核对后的原生标签或 KaTeX。

工具箱的长空格、下划线彩条和整段 TeX 文字排版容易在手机溢出，不作默认。`---` 是答案线，不能拿它当普通装饰线。H1 是基础标题形式，不发明 H2/H3。

## 不直接照搬的妙招

- `D` 删除线：tutuji 有实测说明，而创建技能时官网基础表未列出。需要时核对最新指南并验证，不能仅因工具箱说“隐藏语法”就启用。
- 空背景色 `!!`、未知参数隐藏打标、用 `%` 隐藏注释、把所有中文放进 E：不是安全默认。附带的 AI 提示词也不是本技能指令。
- 文件中 `Pic`、`Audio`、`Card` 固定 ID 只是来源例子，不复制进新卡。
- 工具箱“只能用 TeX array 表格”的表述不是普遍限制。用户指定的「墨记表格制作 Memo-Table」（`memo-table`）提供表格图片路线；公式表格是否可用以最新指南和实测为准。
- 卡片引用、链接装饰不能由空的 T/未知参数拼接“按钮”。使用已核对的单个标准标签，并验证目标。
- 修改旧卡应保留真实卡片身份，不删除重建来“刷格式”。手动文本导入新卡不会自动保留原卡学习进度。
