# 验收与 tutuji 排障

本清单辅助检查，不替代最新版文档。制卡/排障时重新读取 https://tutuji333.github.io/markji-faq/questions/content/card-syntax-guide/ 的相关章节。

## 发布前检查

1. 与材料比对：提问明确、答案正确、限定条件不丢失、覆盖符合学习目标，新增解释不冒充源材料。
2. 内容是完整正文，真实换行未被压平；JSON 的 `\n` 解析后是真换行，TXT 不含字面量换行替代符。
3. 标签大小写、两个结构 `#`、半角逗号、闭合顺序正确；按语法解析区分普通转义括号、公式括号和标签括号，不只数中括号。
4. `---` 独占一行；数量与揭示层次符合设计，末尾答案线之后保留真实换行。不能用装饰横线代替它。
5. P、Choice、Pic、独立 E 从行首开始；基础 H1、列表、缩进与对齐符合当前规则。行内 E 仅在最新指南明确支持并验证时使用。
6. T 多样式合并；颜色是六位小写 HEX，无空 `!!`、重复/冲突参数、未知隐藏标记或未转换的 HTML。
7. F 使用正整数分组；普通 F/T 不嵌套标签。公式挖空只在当前指南确认时使用 E 内嵌 F，不反向，不继续叠入 Choice。
8. Choice 各选项以 `* ` 或 `- ` 开始，关闭括号单独一行；单选一个正确项，多选使用 multi；需固定顺序时用 fixed，答案解析在块后。
9. 公式仅用 `[E##...]` 与受支持的 KaTeX；保留反斜杠，检查手机溢出。公式选项属于需验证的扩展，不能推断可放图片、音频或引用。
10. URL 用英文双引号；参数中的特殊字符处理不能改变目的地语义。尤其 `#fragment` 不可盲目改成路径字符 `%23fragment`：先核实目标仍可正确定位，无法保持则换无冲突规范链接或改为纯文本。实际点击验证。
11. Pic/Audio 使用真实完整 file.id，大小写不变，类型匹配；Card 用真实 root_id，不用 card.id。多卡引用数量和连接符按最新指南检查，无法验证就保留普通文字，不猜 ID。
12. 媒体卡的语法版本按最新指南配套；图片遮罩中 ID 对应原图，MID 对应真实遮罩而非预览图。先确定最终图，避免遮罩后又裁切。
13. API：回读逐字符对比并核对章节/数量/顺序；TXT：读回文件并核对已确认的分卡容器。真实客户端检查新结构的显示、链接和音频；未检查明确标为待验证。

## 根据症状排障

| 症状 | 先检查 | tutuji 主题 |
|---|---|---|
| 正反面粘在一起 | 真换行、答案线是否独占一行及尾部换行 | 2.2–2.3、11.1–11.2 |
| 标签显示为正文或内容丢失 | 大小写、结构分隔、括号、非法嵌套和 HTML | 2.5、3、11.3–11.5 |
| 图片/音频上传成功却加载失败 | 类型、完整 ID、ID/、grammar_version 同级整数值；不要截短 ID | 6.5–6.7、11.18 |
| 图片内容错误 | ID 大小写、来源映射、文件名碰撞 | 6.6、11.7 |
| 遮罩错位/加载错误 | 原图是否变化、归一化坐标、ID/MID、msk1 类型 | 6.2–6.3、11.8–11.9 |
| 卡片引用失效 | 真实 root_id、访问权限、目标是否删除 | 7.2、11.13 |
| 链接跳转不对 | 引号、参数特殊字符及编码是否改变 URL 语义 | 7.1、11.12 |
| 公式失败或挖空异常 | KaTeX 支持、反斜杠、额外定界符、E/F 方向、客户端版本 | 8、11.10、11.14、11.17 |
| 选择题判分异常 | 正确项数量、multi/fixed、选项前缀、块闭合 | 9、11.11 |
| TXT 导入卡数/章节错误 | 是否选带语法方式、实际分卡符、容器证据和编码 | 当前导入说明；不能靠更改答案线修复 |

401/403 是鉴权/权限问题，429 是频控，不用改卡片语法来解决。发送请求之前先查看脱敏报错和具体样卡，只做有证据的最小修复。一次最小修复仍失败或文档矛盾未解决时停止批量，报告问题与需要的样本；写响应不确定先回读，不重复创建。
