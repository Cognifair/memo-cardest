# 表格：墨墨风格图片与 LaTeX array 路线

设计参考：https://github.com/Cognifair/memo-canvas 。本技能不复制其实现，不声称它是官方工具。

## 统一入口：四选一

当前环境有「墨兰迪 Memo-Canvas」（`memo-canvas`）技能时，读取并按它的 SKILL.md 操作；该技能同时支持墨墨风图片与裸 `array` 表格代码，不授权上传或编辑卡片。旧名 `memo-table` 是本地兼容入口，会转入 `memo-canvas`，不是另一个维护路线。

用户未选定完整模式时，按该技能先询问四选一：① 墨墨风图片生成 直角；② 墨墨风图片生成 圆角；③ LaTeX 表格生成 三线表；④ LaTeX 表格生成 网格表。已经选定时不重复询问，不在主技能里先问旧的两选项问题；会员确认不能替代表格模式选择。LaTeX 线型已确定后也不再重复询问。

## 透明 PNG（选项 ①/②，适合较复杂排版）

`memo-canvas` 不可用或调用失败时，按主技能 G1.5 报告缺失，表格卡标“待处理”，可继续非表格卡；不自动改用上游仓库实现或本地手写。只有用户明确要求不用 `memo-canvas` 才按其选择另行确认替代路线，不能把来源链接当成下载、安装或执行授权。

默认表外透明、绿色标题与绿色表头、白色表头字、首列淡绿半透明、正文透明背景及深绿字；优先 CJK 字体，约 2000px 宽。尊重用户主题，检查深绿文字在暗背景的对比度，不承诺透明 PNG 自动兼容所有夜间模式。

保留输入数据和措辞；仅为排版调整换行，不擅改事实。输出 PNG 与可编辑 HTML，检查中文字体、列宽、裁切、换行、手机可读性、alpha 通道与透明角像素。需要时拆成几张表，不压缩到无法阅读。

- API 路线：仅在已授权制卡任务内上传 PNG，拿真实 file.id 后嵌入卡片，回读并实际预览。
- TXT 路线：交付 PNG/HTML 与 TXT；让学习者自行导入后插图，没有媒体 ID 不伪造引用，不因已开通专业版而改走账户上传。

## 简短公式表格

选项 ③/④ 先由 `memo-canvas` 按其 `references/array-tables.md` 生成裸 `array` 代码：三线表默认左对齐且只有三条横线；网格表居中、带竖线且每行有横线。只有用户进一步要求嵌入卡片时，才由本技能处理下述正文包装与平台验收，不要求表格技能自行输出卡片标签或 API 请求。

确需可编辑数学/化学小表时，按官网与 tutuji 最新公式说明，在 `[E##...]` 内使用已支持的 KaTeX 环境，例如核对后的 `array`。不嵌套 `$...$` 或其他公式定界符，不加载额外宏包。

工具箱中的“仅支持 array”“中文不能用 text”“化学式不能用 mathrm”等示例限制不是通用规则；按当前 KaTeX 支持和产品实测决定。复杂对照表通常优先图片。未经验证不把表格图片嵌进 Choice 选项，也不组合公式选项和公式挖空产生三层结构。
