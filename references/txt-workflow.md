# TXT 路线：交给 Memo-TXT

选 TXT 后先确认/询问会员状态并记录 `member: pro|free`、`char_limit: 4500|1800`，再调用 `memo-txt`（`skill` 工具，name=memo-txt）。cardest 不本地封装 TXT、不复制容器格式、不自己写导入教程。TXT 的会员问题只用于字数上限，不询问/读取 API 凭证。

先区分普通 TXT 文件交付与明确选择的官网媒体中转；不把“要带图的 TXT”或“不要 API”当作账号写入授权。已有的 OpenAPI 图片后回填仍由 Memo-TXT 维护，须另行确认，不能自动替代官网路线。

## 交接内容

- 牌组名称/简介、章节映射、卡片正文（原生 Markji 语法）、顺序与卡片数。
- `member: pro|free` 与 `char_limit: 4500|1800`；每张卡已按该上限检查。未指定时 MT 按 free/1800 校验。
- 媒体：发布正文只引用获授权且来源可核对的真实媒体 ID，不留伪造 ID、文件路径或占位 Pic。普通文件交付没有可用引用时，交正文和独立媒体清单；官网中转的内部模板可使用 Memo-TXT 的编号占位符，回填后不得残留。
- 旧卡更新：TXT 不保留旧 ID、链接或学习进度，先说明；需要覆盖时让用户提供当前产品支持的格式并先备份。

## 普通文件交付

- `references/container-format.md`：容器格式与样本证据；
- `scripts/lint_txt.py`：结构校验；
- `scripts/cli.py finalize <TXT> --member pro|free`：先按 4500/1800 硬上限（4000/1600 软提醒）校验，再输出教程 + GIF + 平台上限/本次上限 + `交付自检：导入教程已附`；按实际脚本输出交付，不另维护步骤数量或教程副本；
- `references/import-guide.md` / `.html`：图文指南。

- 未安装 Memo-TXT 或校验失败：**停止 TXT 文件交付**，说明原因；不要本地兜底复制格式或教程。
- 不读取凭证、不访问账户、不替用户导入。交付消息按普通 Markdown 原样附校验输出；缺教程或自检标记就标「未完成」。
- 只有用户明确说“不用教程”时可省略教程，并说明这次省略了；仍需运行校验，不得为省略教程跳过验证，也不得在未附教程时声称“导入教程已附”。
- 具体按钮以当前官方说明或用户客户端为准，不凭历史截图编造。

## 官网媒体中转（不使用 OpenAPI）

1. 确认安装的 Memo-TXT 支持 `scripts/cli.py web-media --help`（v1.4.0 起），读该技能的 `references/web-media.md`。Cardest 只交接卡片设计、章节、字数上限、媒体映射和授权范围，不复制 Playwright 实现。
2. 交接已打包的图片/音频 APKG、已有中转牌组或真实导出 TXT，以及带编号占位的目标模板。没有上述输入时说明还需打包；不声称 Memo-TXT 自动生成或切分 APKG。表格/重绘资产仍按 Memo-Canvas 交接。
3. 确认本次登录账号、上传文件、目标牌组/章节和提交范围。上传 APKG 会新建中转牌组；默认停在最终预览，明确授权自动导入才加 `--commit`。凭证不经 Cardest，不请求 API Key、Cookie 或密码。不经授权不删中转牌组。
4. 按实际验收报告卡数、独立回读、图片显示与音频播放；提交不确定先只读核查。网页粘贴正文不强行套普通 TXT 的结尾或 `finalize` 交付规则。已验证同账号媒体复用及目标提交回读；Playwright 自动上传 APKG 的真实官网整链仍待验。
