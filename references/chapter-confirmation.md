# 章节切分确认门禁

章节切分影响卡片归属、复习顺序和后续改卡。**模糊提到“章节”不等于确认。**

## 判定

### 可以直接跳过提问

用户明确说了切法，例如：

```text
按人教版教材章节
按课本目录
按一级标题
每章一个章节
整份不切分
```

要求：

- 原话能落到具体结构；
- 不是只说了“按章节 / 按教材 / 分一下”；
- 新材料、新任务、新牌组要重新判定。

### 必须提问

```text
按章节分
按教材
分一下
看看怎么分
你决定
```

或者材料存在多种合理切法、跨章题、目录层级不清。

问题必须带 2–4 个**基于材料实际结构**的选项：

```text
这份材料我看到三种切法：
① 按一级标题：N 章
② 按课时/模块：M 组
③ 整份不切分
④ 不同，我自己说
```

不能只问“你想怎么分”。

## 新任务重新确认

同一个对话里：

```text
材料变了
牌组/目标章节变了
切分粒度变了
→ 上一次答案不能复用
```

明确说“和上次一样”才可复用，并记录证据。

## chapter_plan.json

生成或写入卡片前保存：

```json
{
  "task_id": "chem-2026",
  "source_material": "C:/.../chemistry.docx",
  "split_mode": "explicit | asked | unresolved",
  "evidence": "用户原话：按人教版教材章节创建",
  "confirmed_by": "user",
  "confirmation_id": "ask-123",
  "chapters": [
    {"name": "必修一 第1章 物质及其变化", "source_heading": "第一章"}
  ]
}
```

校验：

```text
python -B scripts/check_chapter_plan.py chapter_plan.json
```

未通过：

```text
不生成卡片
不写入牌组
不进入批量上传
```

## ask_user_question 不可用

不能默认继续。改为在回复里列出编号问题并停止：

```text
这次先不写卡。请确认章节切分：
① ...
② ...
③ 不同，我自己说
```

## goal / 自动续跑

自动续跑不能绕过门禁：

```text
目标未确认章节切分
→ 本轮停在 G1
→ 不为了“有进展”自动分类
```

## 回归用例

```text
多章节材料 + 用户没说切法 → 必须问，0 张卡
用户说“按人教版” → 可以跳过
用户说“按章节分” → 必须问
同会话新任务换材料 → 必须重新问
ask 工具不可用 → 文字提问并停止
```
